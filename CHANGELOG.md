# Changelog

## 1.0.0 - 2026-10-26

- Initial Horse Derby release.
- 15-second pre-race countdown by default.
- Four animated pixel horses on separate lanes.
- Randomized finishing order for every race.
- Predetermined crossing times guarantee the selected winner crosses first, followed by 2nd, 3rd, and 4th in order.
- Variable pace animation during the race.
- Approximately 30-second race duration by default.
- 15-second results screen by default.
- Configurable timings and lane-number display.
- 128x32 reference layout with dynamic display-size reads.
